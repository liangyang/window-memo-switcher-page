Windows 11 に常駐 · keyboard-first

切り替える。 残す。 あとから見つける。

仕事の資料も、旅行の計画も、推し活のメモも。ウィンドウ切替・画面キャプチャ・付箋メモ・履歴検索を、ひとつの操作面で扱うWindows向け常駐ツールです。

  • Ctrl+Shift+Space 切替
  • Ctrl+W 範囲キャプチャ
  • Ctrl+Shift+M 付箋メモ
  • Ctrl+F 履歴検索

Live demo

作業の入口と記録を、ひとつにまとめる。

開いているウィンドウへ戻る、よく使う資料を開く、作業ログをたどる、画面を切り取って残す。日々の細かい移動と記録を、同じ画面で扱えます。

  • 大量に開いたExcelやWordをファイル名一覧からすぐ選択
  • お気に入りのフォルダー、ファイル、URLを起動
  • Ctrl + Wで指定ウィンドウの指定領域を付箋メモへ貼り付け
  • 貼った画像にペン、直線、四角、矢印、文字で書き込み
  • メモと画像を履歴に残し、キーワードで探し直す
  • 作業ログから1日の流れを確認AI日報はBOOTH版では非対応
  • 割り込み前に「中断しおり」で作業状態を保存、1クリックで復帰
  • 範囲指定の録画、録音、音声入力、文字起こしBOOTH版では非対応
  • 必要な履歴をExcel / ZIPで出力

Use cases

仕事も、暮らしの段取りも。

資料づくりの合間にホテルを比較して、レシピを保存して、また仕事に戻る。画面を何度も行き来する毎日の、開く・戻る・残す・探すを短い操作にまとめます。

Ctrl+Shift+Space ウィンドウ切替

大量に開いたExcelやWordも、ファイル名の一覧から探してすぐ前面に戻せます。

favorites お気に入り起動

よく使うフォルダー、ファイル、URLをグループごとに整理して開けます。

Ctrl+W 画面キャプチャ

予約ページの比較も、動画の一場面も。指定した領域だけをCtrl+Wで切り取ってメモに貼れます。

Ctrl+F 履歴と作業ログ

残したメモと開いた資料の流れを、あとから検索してたどれます。

Features

切替、記録、検索、日報まで。

開いている画面へ戻る、気づきを画像ごと残す、あとから探し直す。さらに中断からの復帰やAIによる日報作成まで、1日の流れをまるごと支えます。

Ctrl+W capture & memo

気になった画面を、そのままメモに。

  • ホテルの予約ページ、レシピ動画、会議資料。指定した範囲だけをCtrl+Wで付箋メモへ
  • グループ、タイトル、本文、画像でさっと整理
  • ピン留め、ゴミ箱で状態を分けて管理
  • 録画、録音、音声入力のボタンもメモ画面にBOOTH版では非対応
AI daily report BOOTH版では非対応

今日やったことは、AIが日報にする。

  • 開いていた資料と時間の記録から、AIが日報の下書きを自動生成
  • 【今日の作業】【メモ・気づき】【明日の予定】まで整った形で出力
  • そのまま編集してコピーするだけ。日報のために記憶をたどる時間をゼロに
interruption bookmark

割り込みが来ても、迷わず戻れる。

  • 宅配、電話、急な呼び出し。中断前に「しおり」を1枚挟むだけ
  • ひとことメモと、開いていたウィンドウの状態をまとめて記録
  • 戻ったら1クリックで作業中の画面へフォーカス復帰
Ctrl+F recall

「あれどこだっけ」を、検索で終わらせる。

  • 残したメモと画像を日付別、グループ別に一覧
  • キーワード検索で数週間前のメモも一瞬で発掘
  • 画像付き、動画付き、音声付きだけの絞り込みも
  • 必要な分だけExcel / ZIPで出力
Ctrl + W

指定範囲キャプチャ

残したい部分をドラッグでなぞるだけ。ウィンドウごと、領域ごとに切り取って、そのまま付箋メモに貼り付きます。Web会議や動画の一場面にも。

annotate

画像編集ツール

貼り付けた画像に、ペン、直線、四角、矢印、文字で書き込み。あとから移動や削除もできます。

switch

ウィンドウ切替

大量に開いたExcelやWordも、ファイル名の一覧からキーボードで選ぶだけ。プレビューを目で追う時間がなくなります。

favorites

お気に入り

よく使うフォルダー、ファイル、URLをグループで整理。それぞれにメモも添えられます。

worklog

作業ログ

開いたウィンドウと資料を日別に自動記録。何にどれだけ時間を使ったかが、サマリでひと目で分かります。

record & voice

録画も、録音も、声のメモも。 BOOTH版では非対応

範囲指定の動画録画、会議の録音、音声入力と文字起こし、AIへの問い合わせ・翻訳・要約まで。付箋メモの下のボタンから、そのまま使えます。

BOOTHで配布中の無料版について： ウィンドウ切替・お気に入り・範囲キャプチャ・画像編集・付箋メモ・履歴検索・作業ログ・中断しおり・Excel / ZIP出力はそのままお使いいただけます。 AI日報、範囲録画、録音、音声入力、文字起こし、AI連携（問い合わせ・翻訳・要約）は、現在BOOTHで配布している版には含まれていません。
