Window Memo Switcher

作業中のウィンドウ、資料、フォルダー、画像メモ、履歴をひとつの操作面から扱うWindows向け常駐ツールです。

BOOTHで見る ↗ 実画面を見る ↓
  • Ctrl + Shift + Space で切替
  • お気に入りから資料を開く
  • Ctrl + Shift + M で付箋
  • 画像つきメモに対応
  • Ctrl + Wで指定範囲を貼り付け
  • 履歴検索・お気に入り・作業ログ

作業の入口と記録をまとめます。

開いているウィンドウへ戻る、よく使う資料を開く、作業ログをたどる、画面を切り取って残す。日々の細かい移動と記録を同じ画面で扱えます。

  • 大量に開いたExcelやWordをファイル名一覧からすぐ選択
  • お気に入りのフォルダー、ファイル、URLを起動
  • 作業ログから直近の流れを確認
  • Ctrl + Wで指定ウィンドウの指定領域を付箋メモへ貼り付け
  • Web会議やYouTubeなどの動画の一場面を、必要な部分だけ切り取って保存
  • 貼った画像にペン、直線、四角、矢印、文字で書き込み
  • メモ、画像、Todoを履歴として保存
  • 検索欄からキーワードで素早く探し直す
  • 必要な履歴をExcel / ZIPで出力

何度も画面を行き来する作業へ。

Excel、Word、Chromeなどのブラウザ、フォルダーを何度も往復する作業で、開く・戻る・残す・探すを短い操作にまとめます。

ウィンドウ切替

大量に開いたExcelやWordも、ファイル名の一覧から探してすぐ前面に戻せます。

お気に入り起動

よく使うフォルダー、ファイル、URLをグループごとに整理して開けます。

画面キャプチャ

Web会議やYouTubeなどの動画の一場面も、指定した領域だけをCtrl+Wで切り取ってメモに貼れます。

履歴と作業ログ

残したメモと開いた資料の流れを、あとから検索してたどれます。

切替、起動、記録、検索。

Window Memo Switcherは、作業中の移動と記録を支える常駐ツールです。開いている画面へ戻る、よく使う資料を開く、気づきを画像ごと残す操作をまとめて扱えます。

必要な画面を、必要な形で残す。

  • 作業中に気づいた内容をグループ、タイトル、本文、画像で保存
  • 貼り付けた画像にペン、直線、四角、矢印、文字を入れて、そのままメモ化
  • 書き込んだ内容は後から移動、削除、文字編集が可能
  • Todo、ピン留め、ゴミ箱で状態を分けて整理
  • Ctrl + Wで指定ウィンドウの指定領域をそのままメモへ貼り付け
  • Web会議、YouTubeなどの動画、資料画面の一部を必要な形で切り貼り

作業の続きに戻りやすい。

  • 残した付箋メモを日付別、グループ別に確認
  • キーワード検索で過去のメモを探し直し
  • 画像付きメモだけを絞り込み
  • 必要な履歴をExcel / ZIPで出力

指定範囲キャプチャ

Ctrl+Wで、指定したウィンドウの必要な部分だけを切り取り、付箋メモへ貼り付けられます。Web会議や動画、資料画面の一場面を残すときに使えます。

画像編集ツール

貼り付けた画像に、ペン、直線、四角、矢印、文字でメモを書き込めます。書き込んだ内容は後から移動や削除もできます。

ウィンドウ切替

Windowsのプレビューでは追いづらい大量のExcelやWordも、ファイル名の一覧からキーボードで選べます。

お気に入り

よく使うフォルダー、ファイル、URLをグループ化し、関連メモも一緒に持てます。

作業ログ

直近で開いたウィンドウや資料を日別にたどり、作業の流れを後から確認できます。
